🌙 오복사주

계정 및 데이터 삭제 안내

오복사주(주식회사 제이브로컴패니)는 이용자가 자신의 계정과 데이터를 직접, 즉시 삭제할 수 있도록 아래 방법을 제공합니다. 오복사주는 이용자 정보를 서버에 저장하지 않으며, 모든 정보는 이용자 기기에만 저장됩니다.

삭제 방법

  • 회원 탈퇴 (계정 + 데이터 전체 삭제): 앱 실행 → [MY] → [회원 탈퇴] 를 선택하면 계정과 저장된 모든 정보가 기기에서 즉시 삭제됩니다.
  • 데이터만 삭제 (계정 유지): 앱 실행 → [MY] → [사주 정보 지우기] 를 선택하면 저장된 사주 정보가 삭제됩니다.
  • 전체 초기화: 기기 설정에서 앱의 저장소·데이터를 삭제하거나 앱을 제거하면 모든 저장 정보가 사라집니다.

삭제되는 데이터 유형

  • 이름 또는 별명, 성별, 생년월일, 태어난 시각
  • 회원 계정 정보(이메일, 비밀번호 — 단방향 암호화하여 저장한 값)
  • 상담 시 입력한 내용, 궁합·관계 리포트를 위해 입력한 상대방 생년월일

보관 기간

오복사주는 위 정보를 서버에 전송·보관하지 않으며, 정보는 이용자 기기(브라우저 로컬 저장소)에만 저장됩니다. 위 방법으로 삭제하면 해당 정보는 즉시 삭제되고 복구할 수 없으며, 별도로 서버에 보관되는 데이터는 없습니다.
